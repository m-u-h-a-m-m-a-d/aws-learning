## 🎯 Quick Facts

| Item | Details |
|------|---------|
| **What is SNS?** | Fully managed pub/sub messaging service |
| **Core Model** | Publish-Subscribe (one-to-many messaging) |
| **Key Benefit** | Broadcast to thousands with one API call |
| **Pricing** | Pay-per-use, no minimum fees |
| **Free Tier** | 1M push, 1K email, 100K HTTP/HTTPS per month |
| **Best For** | Event-driven apps, notifications, decoupling services |
| **Don't Use For** | Long-term storage, guaranteed ordering |
